## Topic
在阿里云IoT平台中，物模型的topic通常遵循以下格式：
```C

/${productKey}/${deviceName}/user/update
```
其中，`${productKey}` 和 `${deviceName}` 是你的设备在阿里云IoT平台上的唯一标识。

将你的数据封装成JSON格式，然后发布到这个topic
```C
case MQTT_EVENT_CONNECTED:
    ESP_LOGI(TAG, "MQTT_EVENT_CONNECTED");
    char *payload = "{\"temperature\": 23.5}";
    msg_id = esp_mqtt_client_publish(client, "/${productKey}/${deviceName}/user/update", payload, 0, 1, 0);
    ESP_LOGI(TAG, "sent publish successful, msg_id=%d", msg_id);
    break;
```

#### 标准json格式
```Json
{
    "id": "123",
    "version": "1.0",
    "sys":{
        "ack":1
    },
    "params": {
       "device_tmep":30.5
    },
    "method": "thing.event.property.post"
}
```

params：表示参数。
"key":value

key分两种
自定义的和非自定义的，本系统采用自定义的
写法为：device_temp
value是数值，所以不需要加引号

## tips
- 需要确保你的设备有权限发布消息到这个topic，这通常需要在阿里云IoT平台上为设备设置合适的权限。
- 在阿里云IoT平台中，你不需要手动创建topic。当你在物模型中定义了属性后，阿里云IoT平台会自动为你生成对应的topic。
## 错误及解决办法
### 连接失败
`no active session`---520
#### 原因
1. 设备的ProductKey、DeviceName或DeviceSecret不正确。请检查你的代码中的这些值是否与阿里云IoT平台上的设备信息匹配。
2. 设备的MQTT客户端配置不正确。请检查你的代码中的MQTT客户端配置，特别是服务器URI、用户名、密码和客户端ID。
3. 设备的网络连接有问题。请检查设备是否可以正常连接到互联网，并且可以访问阿里云IoT平台的服务器。
4. 设备的时间设置不正确。在MQTT协议中，设备需要提供一个时间戳来生成签名。如果设备的时间设置不正确，这可能会导致签名无效。
#### 解决方式
1. 检查设备的ProductKey、DeviceName和DeviceSecret是否正确。
2. 检查设备的MQTT客户端配置是否正确。
3. 检查设备的网络连接。
4. 检查设备的时间设置。
### 连接成功但无法更新
- 消息的内容格式不正确。请确保你的消息是一个有效的JSON对象，且包含了物模型中定义的所有属性。
- 消息的topic不正确。请确保你发布消息的topic与物模型中定义的topic一致。
- 设备的权限设置不正确。请检查你的设备是否有权限发布消息到这个topic。
### 连接一段时间后断开
- 检查设备的网络连接。
- 检查设备的MQTT客户端配置。
- 增加设备发送数据的频率，或者发送一个心跳消息来保持连接。
#### 原因
- 多个MQTT客户端可以使用相同的方式连接到阿里云，但是每个客户端必须有一个唯一的客户端ID。如果两个客户端使用相同的客户端ID连接到服务器，服务器会断开已经连接的客户端。

#### 阿里云设备调试页面
#### 在设备上安装一个MQTT客户端，然后订阅设备发布消息的topic。
- 打开MQTTX，点击左上角的"Connect"按钮创建一个新的连接。
- 在"Host"字段中输入你的MQTT服务器的地址，这应该是你在阿里云IoT平台上的MQTT服务器地址。
- 在"Port"字段中输入你的MQTT服务器的端口，对于阿里云IoT平台，这通常是1883或者8883。
- 在"Username"和"Password"字段中输入你的设备的ProductKey和DeviceSecret。
- 点击"Connect"按钮连接到MQTT服务器。
- 连接成功后，点击左侧的"Subscribe"按钮订阅设备发布消息的topic。这应该是"/${productKey}/${deviceName}/user/update"，你需要将${productKey} 和 ${deviceName} 替换为你的设备的实际值。
- 订阅成功后，每当设备发布一条消息，你就可以在MQTTX的"Received Message"区域看到这条消息的内容。
