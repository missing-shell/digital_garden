# 安装命令
## 命令
```CMD
docker run -d --name emqx -p 1883:1883 -p 8083:8083 -p 8084:8084 -p 8883:8883 -p 18083:18083 emqx/emqx:latest
```
* 这行命令是用来在 docker 中运行一个名为 emqx 的容器，它是一个开源的物联网消息中间件，支持 MQTT 协议。这样你就可以创建一个新的容器，并将它的端口映射到你的主机上的端口，以便你可以访问它的服务。
### 命令解释
* `-d` 表示以后台模式运行容器，不会占用你的终端。
* `--name emqx` 表示给容器起一个名字为 emqx ，方便你以后管理和操作它。
* `-p 1883:1883 -p 8083:8083 -p 8084:8084 -p 8883:8883 -p 18083:18083` 表示将容器内部的端口映射到主机上的同样的端口。这些端口分别对应 emqx 的不同的服务，例如：
    * `1883` 是 MQTT 协议的标准端口，用于客户端和服务器之间的通信。
    * `8083` 是 MQTT over WebSocket 的端口，用于支持浏览器或者 Web 应用程序访问 MQTT 服务。
    * `8084` 是 MQTT over WebSocket (SSL) 的端口，用于支持安全的 Web 访问。
    * `8883` 是 MQTT over SSL 的端口，用于支持加密的客户端和服务器之间的通信。
    * `18083` 是 emqx 的管理控制台的端口，用于提供 Web 界面来监控和管理 emqx 的状态和配置。
# 概述
EMQX 是一款[开源](https://github.com/emqx/emqx)、高度可扩展且功能丰富的 MQTT 代理，专为物联网和实时消息应用程序而设计。它支持每个集群多达 1 亿个并发 IoT 设备连接，同时保持每秒 100 万条消息的吞吐量和毫秒级的延迟。

EMQX 支持各种协议，包括 MQTT（3.1、3.1.1 和 5.0）、HTTP、QUIC 和 WebSocket。它还通过 TLS/SSL 和各种身份验证机制提供与 MQTT 的安全双向通信，确保物联网设备和应用程序的可靠、高效的通信基础设施。

端口18083是EMQX的Dashboard监听的端口，它提供了一个Web界面来查看和管理MQTT broker的状态。您可以通过浏览器访问这个端口来查看Dashboard。

然而，端口1883是MQTT broker监听的端口，它用于处理MQTT协议的连接和消息。这个端口通常不是用来通过浏览器访问的，而是用于MQTT客户端（如您的ESP32设备）连接到broker。因此，您无法在浏览器中打开http://localhost:1883是正常的，这不会影响您的ESP32设备连接到broker。

如果您的ESP32设备和Docker主机在同一网络中，您应该能够使用Docker主机的IP地址和端口1883来连接到broker。如果您仍然无法连接，可能需要检查您的网络设置，或者检查Docker是否已经正确配置为将端口1883映射到主机。
