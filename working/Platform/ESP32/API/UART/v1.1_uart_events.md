### 思路
* 通过创建一个专门的任务来处理UART事件，从而实现对UART的高效管理。
* **初始化UART**：在`app_main`函数中，首先进行UART的初始化。这包括设置UART的配置参数（如波特率、数据位、停止位、流控制等），安装UART驱动，并获取事件队列的句柄。然后，设置UART的引脚，并启用模式检测中断。
* **创建任务处理UART事件**：在初始化UART后，创建一个FreeRTOS任务`uart_event_task`来处理UART事件。这个任务会持续监听UART事件队列，当有事件发生时，进行相应的处理。
* **处理UART事件**：在`uart_event_task`任务中，根据事件的类型进行相应的处理。例如，当接收到数据时，读取数据并将其回显到控制台；当检测到硬件FIFO溢出时，清空输入缓冲区并重置事件队列；当检测到UART帧错误时，打印错误信息等。
* **处理UART模式检测事件**：在处理UART事件的过程中，特别地，当检测到UART模式（这里是连续的'+'字符）时，读取并打印出模式前的数据和模式数据。
