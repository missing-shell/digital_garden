#### 概述
* 使用了ESP-IDF框架和LVGL库来驱动一个LCD屏幕并显示图形用户界面。
* 定义了一些函数原型，这些函数用于处理LVGL的UI、读取触摸屏的数据、获取坐标、通知LVGL刷新准备就绪、LVGL的刷新回调、LVGL的更新回调、LVGL的触摸回调、增加LVGL的tick等。
* 然后，代码实现了这些函数，包括读取触摸屏的数据、测试触摸屏、获取坐标、通知LVGL刷新准备就绪、LVGL的刷新回调、LVGL的更新回调、LVGL的触摸回调等。
* 最后，代码的主函数`app_main`初始化了LCD面板、I2C总线、LVGL库，注册了显示驱动到LVGL，安装了LVGL的tick定时器，注册了输入设备驱动到LVGL，然后显示了LVGL的UI，并进入了一个无限循环，周期性地调用LVGL的定时器处理函数。
* 主要目标是初始化硬件（如LCD面板、I2C总线等），设置LVGL库，然后显示图形用户界面，并处理用户的触摸输入。

#### uint8_t cst816t_read_len(uint16_t reg_addr,uint8_t * data,uint8_t len)

* **通过I2C总线从CST816T触摸传感器读取数据。**
* `uint16_t reg_addr`：这是你想要读取的寄存器地址。
* `uint8_t * data`：这是一个指向存储读取数据的缓冲区的指针。
* `uint8_t len`：这是你想要读取的数据的长度。
```c++
uint8_t cst816t_read_len(uint16_t reg_addr,uint8_t * data,uint8_t len)
{
    uint8_t res=0;
    res = i2c_master_write_read_device(I2C_HOST, CST816T_SENSOR_ADDR, &reg_addr, 1, data, len, I2C_MASTER_TIMEOUT_MS / portTICK_PERIOD_MS);
    return res;
}
```
#### static esp_err_t testtouch(uint8_t *touch_points_num)

* **测试触摸屏是否被触摸，并获取触摸点的数量。**
* `cst816t_read_len`函数的作用是从CST816T触摸传感器的指定寄存器读取数据。
* `FingerNum`：这是你想要读取的寄存器地址，代表触摸点的数量。
* `touch_points_num`：这是一个指向存储读取数据的变量的指针，即触摸点的数量。
* `1`：这是你想要读取的数据的长度，这里是触摸点数量的长度，所以是1。
```c++
static esp_err_t testtouch(uint8_t *touch_points_num)
{
    uint8_t res=0;
    res = cst816t_read_len(FingerNum, touch_points_num,1);
    return res; 
}
```
#### esp_err_t get_coordinates(uint16_t *x, uint16_t *y)

* **从触摸屏控制器读取触摸点的坐标，并将这些坐标存储在指定的内存位置。**
* `uint16_t *x` 和 `uint16_t *y`，这两个参数都是指向 `uint16_t` 类型的指针，用于存储从触摸屏控制器读取的坐标值。
* 调用 [[v1.1_lcd_p169h002_ctp#uint8_t cst816t_read_len(uint16_t reg_addr,uint8_t * data,uint8_t len)]]从触摸屏控制器的 `XposH` 寄存器读取4个字节的数据，并将这些数据存储在 `data` 数组中。
```c++
esp_err_t get_coordinates(uint16_t *x, uint16_t *y)
{
    uint8_t data[4];
    int a, b;
    cst816t_read_len(XposH, data,4);
    a = ((data[0] & 0x0f) << 8) | data[1];
    b = ((data[2] & 0x0f) << 8) | data[3];
    if ((a<=240) && (b<=280))
    {
        *x = a;
        *y = b;
    }
    return ESP_OK;
}
```
#### static bool notify_lvgl_flush_ready(esp_lcd_panel_io_handle_t panel_io, esp_lcd_panel_io_event_data_t *edata, void *user_ctx)

* **一个回调函数，用于在LCD面板IO完成一次颜色数据传输后通知LVGL库。**
* `panel_io`：一个指向LCD面板IO实例的句柄。
* `edata`：一个指向事件数据的指针，这个数据通常包含了关于LCD面板IO事件的信息，例如错误代码等。
* `user_ctx`：一个指向用户上下文的指针，这个上下文在注册回调函数时由用户提供，可以是任何用户需要在回调函数中使用的数据。
 * **
* 首先，它将`user_ctx`强制转换为`lv_disp_drv_t *`类型的指针，这是因为在这个上下文中，用户上下文被假定为一个指向LVGL显示驱动实例的指针。
* 然后，它调用`lv_disp_flush_ready`函数，通知LVGL库，LCD面板IO已经完成了一次颜色数据的传输，LVGL库可以开始处理下一批颜色数据了。
* 最后，函数返回`false`。这是因为在ESP-IDF的LCD面板IO框架中，这个回调函数的返回值用于决定是否需要继续传输更多的颜色数据。返回`false`表示不需要继续传输，返回`true`表示需要继续传输。在这个函数中，返回`false`是因为一旦颜色数据传输完成，就没有更多的数据需要传输了。
```c++
static bool notify_lvgl_flush_ready(esp_lcd_panel_io_handle_t panel_io, esp_lcd_panel_io_event_data_t *edata, void *user_ctx)
{
    lv_disp_drv_t *disp_driver = (lv_disp_drv_t *)user_ctx;
    lv_disp_flush_ready(disp_driver);
    return false;
}
```
#### static void lvgl_flush_cb(lv_disp_drv_t *drv, const lv_area_t *area, lv_color_t *color_map)

* **LVGL图形库的一个回调函数，用于在LCD屏幕上绘制图像。**
* 工作原理是，当LVGL需要在屏幕上绘制图像时，它会调用这个函数，并传入一些参数，包括一个指向显示驱动的指针、一个定义了需要绘制的区域的结构体，以及一个颜色映射表。
* `v_disp_drv_t *drv`：这是一个指向LVGL显示驱动的指针。显示驱动包含了一些关于显示设备的信息，如分辨率、颜色深度等。在这个函数中，它主要被用来获取用户数据（在这个例子中是LCD面板句柄）和屏幕旋转状态。
* `const lv_area_t *area`：这是一个定义了需要绘制的区域的结构体。它包含了四个坐标值：x1、y1（左上角的坐标）和x2、y2（右下角的坐标）。这个区域是相对于整个屏幕的。
* `lv_color_t *color_map`：这是一个颜色映射表，它包含了需要绘制的每个像素的颜色信息。
* 函数内部，首先通过`drv->user_data`获取到LCD面板的句柄，然后根据屏幕的旋转状态（`drv->rotated`），调用`esp_lcd_panel_draw_bitmap`函数在不同的位置绘制图像。这个函数的参数包括LCD面板句柄、绘制区域的坐标和颜色映射表。
* 函数中的坐标偏移（如`offsetx1 + 20`）是为了在屏幕上正确地定位图像。这个偏移值可能需要根据你的具体硬件和设计进行调整。
```c++

static void lvgl_flush_cb(lv_disp_drv_t *drv, const lv_area_t *area, lv_color_t *color_map)
{
    esp_lcd_panel_handle_t panel_handle = (esp_lcd_panel_handle_t) drv->user_data;
    int offsetx1 = area->x1;
    int offsetx2 = area->x2;
    int offsety1 = area->y1;
    int offsety2 = area->y2;
    switch (drv->rotated) {
    case LV_DISP_ROT_NONE:
        esp_lcd_panel_draw_bitmap(panel_handle, offsetx1, offsety1 + 20, offsetx2 + 1, offsety2 + 21, color_map);
        break;
    case LV_DISP_ROT_90:
        esp_lcd_panel_draw_bitmap(panel_handle, offsetx1 + 20, offsety1, offsetx2 + 21, offsety2 + 1, color_map);
        break;
    case LV_DISP_ROT_180:
        esp_lcd_panel_draw_bitmap(panel_handle, offsetx1, offsety1 + 20, offsetx2 + 1, offsety2 + 21, color_map);
        break;
    case LV_DISP_ROT_270:
        esp_lcd_panel_draw_bitmap(panel_handle, offsetx1 + 20, offsety1, offsetx2 + 21, offsety2 + 1, color_map);
        break;
    }
}
```

#### static void lvgl_touch_cb(lv_indev_drv_t * drv, lv_indev_data_t * data)

* **处理触摸屏的输入，获取触摸点的坐标，并根据触摸点的数量更新触摸屏的状态。**
* `lv_indev_drv_t`类型表示输入设备驱动
* `lv_indev_data_t`类型用于存储输入设备的状态和数据。
* 在函数内部，首先定义了两个变量`touchpad_x`和`touchpad_y`用于存储触摸屏的坐标，以及一个变量`touch_points_num`用于存储触摸点的数量。
* 然后，调用`testtouch`函数检测触摸屏上的触摸点数量，并将结果存储在`touch_points_num`中。
* 如果触摸点数量为1（即有一个触摸点），则调用`get_coordinates`函数获取触摸点的坐标，并将结果存储在`touchpad_x`和`touchpad_y`中。
* 如果这两个坐标都不为0，那么就将这两个坐标赋值给`data->point.x`和`data->point.y`。然后，将`data->state`设置为`LV_INDEV_STATE_PRESSED`，表示触摸屏被按下。
* 如果触摸点数量不为1（即没有触摸点或有多个触摸点），那么就将`data->state`设置为`LV_INDEV_STATE_RELEASED`，表示触摸屏被释放。
```c++
static void lvgl_touch_cb(lv_indev_drv_t * drv, lv_indev_data_t * data)
{
    uint16_t touchpad_x = 0;
    uint16_t touchpad_y = 0;
    uint8_t touch_points_num=0;
    testtouch(&touch_points_num);

    if (touch_points_num == 1)
    {
        get_coordinates(&touchpad_x, &touchpad_y);
        if ((touchpad_x != 0) && (touchpad_y != 0))
        {
            data->point.x = touchpad_x;
            data->point.y = touchpad_y;
        }
        data->state = LV_INDEV_STATE_PRESSED;
    } else 
    {
        data->state = LV_INDEV_STATE_RELEASED;
    }
}

```
#### static void increase_lvgl_tick(void *arg)

* **通知LVGL（Light and Versatile Graphics Library，轻量级和通用的图形库）系统时间已经过去了一定的毫秒数。**
* 通常在一个定时器的回调函数中被调用，以此来更新LVGL的系统时间，从而驱动LVGL的各种操作，如动画、界面刷新等。
```c++
static void increase_lvgl_tick(void *arg)
{
    /* Tell LVGL how m any milliseconds has elapsed */
    lv_tick_inc(LVGL_TICK_PERIOD_MS);
}
```

        .pclk_hz = LCD_PIXEL_CLOCK_HZ,
        .lcd_cmd_bits = LCD_CMD_BITS,
        .lcd_param_bits = LCD_PARAM_BITS,
        .spi_mode = 0,
        .trans_queue_depth = 10,
        .on_color_trans_done = notify_lvgl_flush_ready,
        .user_ctx = &disp_drv,
    };
    // Attach the LCD to the SPI bus
    ESP_ERROR_CHECK(esp_lcd_new_panel_io_spi((esp_lcd_spi_bus_handle_t)LCD_HOST, &io_config, &io_handle));

    ESP_LOGI(TAG, "Install ST7789V panel driver");
    esp_lcd_panel_handle_t panel_handle = NULL;
    esp_lcd_panel_dev_config_t panel_config = {
        .reset_gpio_num = PIN_NUM_LCD_RST,
        .rgb_endian = LCD_RGB_ENDIAN_RGB,
        .bits_per_pixel = 16,
    };

    ESP_ERROR_CHECK(esp_lcd_new_panel_st7789v(io_handle, &panel_config, &panel_handle));
    ESP_ERROR_CHECK(esp_lcd_panel_reset(panel_handle));
    ESP_ERROR_CHECK(esp_lcd_panel_init(panel_handle));
    ESP_ERROR_CHECK(esp_lcd_panel_invert_color(panel_handle, true));

    // user can flush pre-defined pattern to the screen before we turn on the screen or backlight
    ESP_ERROR_CHECK(esp_lcd_panel_disp_on_off(panel_handle, true));

    ESP_LOGI(TAG, "Turn on LCD backlight");
    gpio_set_level(PIN_NUM_BK_LIGHT, LCD_BK_LIGHT_ON_LEVEL);

    ESP_LOGI(TAG, "Initialize I2C bus");
    i2c_config_t conf = {
        .mode = I2C_MODE_MASTER,
        .sda_io_num = I2C_MASTER_SDA_IO,
        .scl_io_num = I2C_MASTER_SCL_IO,
        .sda_pullup_en = GPIO_PULLUP_ENABLE,
        .scl_pullup_en = GPIO_PULLUP_ENABLE,
        .master.clk_speed = I2C_MASTER_FREQ_HZ,
    };
    ESP_ERROR_CHECK(i2c_param_config((i2c_port_t)I2C_HOST, &conf));
    ESP_ERROR_CHECK(i2c_driver_install((i2c_port_t)I2C_HOST, conf.mode, 0, 0, 0));

    ESP_LOGI(TAG, "Initialize LVGL library");
    lv_init();
    // alloc draw buffers used by LVGL
    // it's recommended to choose the size of the draw buffer(s) to be at least 1/10 screen sized
    lv_color_t *buf1 = heap_caps_malloc(LCD_V_RES * LCD_H_RES * sizeof(lv_color_t), MALLOC_CAP_DMA);
    assert(buf1);
    lv_color_t *buf2 = heap_caps_malloc(LCD_V_RES * LCD_H_RES * sizeof(lv_color_t), MALLOC_CAP_DMA);
    assert(buf2);
    // initialize LVGL draw buffers
    lv_disp_draw_buf_init(&disp_buf, buf1, buf2, LCD_V_RES * LCD_H_RES);

    ESP_LOGI(TAG, "Register display driver to LVGL");
    lv_disp_drv_init(&disp_drv);
    disp_drv.hor_res = LCD_H_RES;
    disp_drv.ver_res = LCD_V_RES;
    disp_drv.flush_cb = lvgl_flush_cb;
    disp_drv.drv_update_cb = lvgl_port_update_callback;
    disp_drv.draw_buf = &disp_buf;
    disp_drv.user_data = panel_handle;
    lv_disp_t *disp = lv_disp_drv_register(&disp_drv);

    ESP_LOGI(TAG, "Install LVGL tick timer");
    // Tick interface for LVGL (using esp_timer to generate 2ms periodic event)
    const esp_timer_create_args_t lvgl_tick_timer_args = {
        .callback = &increase_lvgl_tick,
        .name = "lvgl_tick"
    };
    esp_timer_handle_t lvgl_tick_timer = NULL;
    ESP_ERROR_CHECK(esp_timer_create(&lvgl_tick_timer_args, &lvgl_tick_timer));
    ESP_ERROR_CHECK(esp_timer_start_periodic(lvgl_tick_timer, LVGL_TICK_PERIOD_MS * 1000));

    static lv_indev_drv_t indev_drv;
    lv_indev_drv_init(&indev_drv);
    indev_drv.type = LV_INDEV_TYPE_POINTER;
    indev_drv.disp = disp;
    indev_drv.read_cb = lvgl_touch_cb;
    //indev_drv.user_data = tp;

    lv_indev_drv_register(&indev_drv);

    ESP_LOGI(TAG, "Display LVGL");
    lvgl_demo_ui(disp);
    // lv_demo_keypad_encoder();
    // lv_demo_benchmark();
    // lv_demo_music();
    // lv_demo_widgets();
    // lv_demo_stress();

    while (1) {
        // raise the task priority of LVGL and/or reduce the handler period can improve the performance
        vTaskDelay(pdMS_TO_TICKS(5));
        // The task running lv_timer_handler should have lower priority than that running `lv_tick_inc`
        lv_timer_handler();
    }
}
