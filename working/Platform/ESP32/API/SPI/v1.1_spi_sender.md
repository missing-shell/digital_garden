* 需和[[v1.1_spi_receiver]]配合使用
### 概述
* 基于ESP-IDF框架的SPI主设备（发送器）的实现。它使用SPI总线与从设备（接收器）进行全双工通信。
* 首先，定义SPI通信相关引脚，以及握手信号(GPIO_HANDSHAKE)。
* 在`gpio_handshake_isr_handler`函数中，当握手线上升时，会触发一个中断服务例程。这个函数会检查两次中断之间的时间间隔，如果间隔小于1ms，就会忽略这次中断。否则，它会给出一个信号量（rdySem），表示从设备已经准备好接收数据。
* `app_main `函数首先配置SPI总线和SPI设备，然后设置握手线的GPIO中断。然后，初始化SPI总线并添加设备。
* 在`while`循环中，程序会等待从设备准备好接收数据（通过等待rdySem信号量）。然后，它会发送一个包含发送次数和上次接收到的数据的消息。接收到的数据会被打印出来，然后发送次数会增加。
#### GPIO_HANDSHAKE
* GPIO_HANDSHAKE is used as a handshake pin. The slave makes this pin high as soon as it is ready to receive/send data. This code connects this line to a GPIO interrupt which gives the rdySem semaphore. The main task waits for this semaphore to be given before queueing a transmission.
### static void IRAM_ATTR gpio_handshake_isr_handler(void* arg)
#### static uint32_t lasthandshaketime_us;
* 定义一个静态变量，用于存储上一次握手线上升沿发生的时间(us),`static`确保该值在函数调用之间会保持不变。
* 静态变量会在程序开始执行时自动初始化为0。
#### if (diff < 1000) { return; }
* 防止由于电气噪声或其他原因导致的误触发(**忽略了在短时间内发生的连续握手线上升沿事件**)。
* 一种消抖策略，原理同[[../GPIO/按键消抖#原理同 V1.1_spi_sender if (diff < 1000) { return; }]]
#### BaseType_t mustYield = false0
* 这是一个标志，用于表示在这个中断服务例程结束后，是否需要进行任务切换。
* 如果在这个中断服务例程中释放了一个信号量，并且有一个优先级更高的任务正在等待这个信号量，那么这个标志会被设置为`true`。
* 这是因为在这种情况下，我们通常希望尽快让优先级更高的任务开始执行。
#### xSemaphoreGiveFromISR(rdySem, &mustYield)
* 释放信号量
* 检查是否有优先级更高的任务正在等待这个信号量。如果有，那么它会通过将`mustYield`设置为`true`来告知我们需要进行任务切换。
#### if (mustYield) { portYIELD_FROM_ISR(); }
* 如果`mustYield`被设置为`true`，那么就会触发一次任务切换，让优先级更高的任务立即开始执行 。

#### code
```c++
/*
This ISR is called when the handshake line goes high.
*/
static void IRAM_ATTR gpio_handshake_isr_handler(void* arg)
{
    //Sometimes due to interference or ringing or something, we get two irqs after eachother. This is solved by
    //looking at the time between interrupts and refusing any interrupt too close to another one.
    static uint32_t lasthandshaketime_us;
    uint32_t currtime_us = esp_timer_get_time();
    uint32_t diff = currtime_us - lasthandshaketime_us;
    if (diff < 1000) {
        return; //ignore everything <1ms after an earlier irq
    }
    lasthandshaketime_us = currtime_us;

    //Give the semaphore.
    BaseType_t mustYield = false;
    xSemaphoreGiveFromISR(rdySem, &mustYield);
    if (mustYield) {
        portYIELD_FROM_ISR();
    }
```

##### 含义
```markdown
- `.command_bits=0`：这个字段设置了命令阶段要发送的位数。在这里，它被设置为0，表示没有命令阶段。
    
- `.address_bits=0`：这个字段设置了地址阶段要发送的位数。在这里，它被设置为0，表示没有地址阶段。
    
- `.dummy_bits=0`：这个字段设置了虚拟（dummy）阶段要发送的位数。在这里，它被设置为0，表示没有虚拟阶段。
    
- `.clock_speed_hz=10000000`：这个字段设置了SPI时钟的速度，单位是赫兹。在这里，它被设置为10,000,000，即10MHz。
    
- `.duty_cycle_pos=128`：这个字段设置了SPI时钟的占空比。在这里，它被设置为128，表示50%的占空比。
    
- `.mode=0`：这个字段设置了SPI的模式。在这里，它被设置为0，表示使用SPI模式0。
    
- `.spics_io_num=GPIO_CS`：这个字段设置了用于SPI片选（CS）的GPIO引脚编号。
    
- `.cs_ena_posttrans=3`：这个字段设置了在传输结束后，CS信号保持低电平的时钟周期数。在这里，它被设置为3，表示在传输结束后，CS信号将保持低电平3个时钟周期。
    
- `.queue_size=3`：这个字段设置了SPI设备队列的大小。在这里，它被设置为3，表示SPI设备队列可以同时容纳3个事务。
```

### 信号量
#### 目的
* 创建信号量 rdySem 来同步主设备和从设备。 信号量在中断服务例程 (ISR) gpio_handshake_isr_handler 中给出，当握手线变高时会触发该信号量。
* 信号量是一种在多线程环境中用于同步和协调线程的机制。在这个代码中，信号量`rdySem`被用作一个握手信号，表示从设备已经准备好接收数据。
```c++
static QueueHandle_t rdySem;
```

* 这个信号量在主设备和从设备之间起到了桥梁的作用。当从设备准备好接收数据时，它会将一个GPIO引脚（在这个代码中是`GPIO_HANDSHAKE`）置高。这个动作会触发一个中断，该中断的处理函数是`gpio_handshake_isr_handler`。在这个处理函数中，信号量`rdySem`被释放
```c++
static void IRAM_ATTR gpio_handshake_isr_handler(void *arg)
{
    // ...
    xSemaphoreGiveFromISR(rdySem, &mustYield);
    if (mustYield)
    {
        portYIELD_FROM_ISR();
    }
}
```

* 在主设备的主循环中，每次在发送数据之前，都会尝试获取这个信号量。如果信号量已经被释放，那么`xSemaphoreTake`函数会立即返回，并且主设备会继续执行发送数据的操作。如果信号量还没有被释放，那么`xSemaphoreTake`函数会阻塞，直到信号量被释放。
```c++
while (1)
{
    // ...
    xSemaphoreTake(rdySem, portMAX_DELAY); // Wait until slave is ready
    ret = spi_device_transmit(handle, &t);
    printf("Received: %s\n", recvbuf);
    n++;
}
```

* 这个信号量实际上是在协调主设备和从设备之间的通信，确保主设备只有在从设备准备好接收数据时才发送数据。

### code
```c++
#include <stdio.h>
#include <stdint.h>
#include <stddef.h>
#include <string.h>
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "freertos/semphr.h"
#include "freertos/queue.h"
#include "driver/spi_master.h"
#include "driver/gpio.h"
#include "esp_timer.h"

/*
SPI sender (master) example.

This example is supposed to work together with the SPI receiver. It uses the standard SPI pins (MISO, MOSI, SCLK, CS) to
transmit data over in a full-duplex fashion, that is, while the master puts data on the MOSI pin, the slave puts its own
data on the MISO pin.

This example uses one extra pin: GPIO_HANDSHAKE is used as a handshake pin. The slave makes this pin high as soon as it is
ready to receive/send data. This code connects this line to a GPIO interrupt which gives the rdySem semaphore. The main
task waits for this semaphore to be given before queueing a transmission.
*/
#define GPIO_HANDSHAKE 21
#define GPIO_MOSI 19
#define GPIO_MISO 20
#define GPIO_SCLK 18
#define GPIO_CS 7
#define SENDER_HOST SPI2_HOST

// The semaphore indicating the slave is ready to receive stuff.
static QueueHandle_t rdySem;

/*
This ISR is called when the handshake line goes high.
*/
static void IRAM_ATTR gpio_handshake_isr_handler(void *arg)
{
    // Sometimes due to interference or ringing or something, we get two irqs after eachother. This is solved by
    // looking at the time between interrupts and refusing any interrupt too close to another one.
    static uint32_t lasthandshaketime_us;
    uint32_t currtime_us = esp_timer_get_time();
    uint32_t diff = currtime_us - lasthandshaketime_us;
    if (diff < 1000)
    {
        return; // ignore everything <1ms after an earlier irq
    }
    lasthandshaketime_us = currtime_us;

    // Give the semaphore.
    BaseType_t mustYield = false;
    xSemaphoreGiveFromISR(rdySem, &mustYield);
    if (mustYield)
    {
        portYIELD_FROM_ISR();
    }
}

// Main application
void app_main(void)
{
    esp_err_t ret;
    spi_device_handle_t handle;

    // Configuration for the SPI bus
    spi_bus_config_t buscfg = {
        .mosi_io_num = GPIO_MOSI,
        .miso_io_num = GPIO_MISO,
        .sclk_io_num = GPIO_SCLK,
        .quadwp_io_num = -1,
        .quadhd_io_num = -1};

    // Configuration for the SPI device on the other side of the bus
    spi_device_interface_config_t devcfg = {
        .command_bits = 0,          // Number of bits in command phase, set to 0 if not used
        .address_bits = 0,          // Number of bits in address phase, set to 0 if not used
        .dummy_bits = 0,            // Number of dummy bits in dummy phase, set to 0 if not used
        .clock_speed_hz = 10000000, // Clock speed for SPI device, in Hz
        .duty_cycle_pos = 128,      // Duty cycle of clock, 128 means 50% duty cycle
        .mode = 0,                  // SPI mode (0, 1, 2, or 3)
        .spics_io_num = GPIO_CS,    // GPIO number for Chip Select (CS) line
        .cs_ena_posttrans = 3,      // Number of clock cycles to keep CS low after a transaction
        .queue_size = 3             // Size of queue for transactions
    };
    // GPIO config for the handshake line.
    gpio_config_t io_conf = {
        .intr_type = GPIO_INTR_POSEDGE,
        .mode = GPIO_MODE_INPUT,
        .pull_up_en = 1,
        .pin_bit_mask = (1 << GPIO_HANDSHAKE)};

    int n = 0;
    char sendbuf[128] = {0};
    char recvbuf[128] = {0};
    spi_transaction_t t;
    memset(&t, 0, sizeof(t));

    // Create the semaphore.
    rdySem = xSemaphoreCreateBinary();

    // Set up handshake line interrupt.
    gpio_config(&io_conf);
    gpio_install_isr_service(0);
    gpio_set_intr_type(GPIO_HANDSHAKE, GPIO_INTR_POSEDGE);
    gpio_isr_handler_add(GPIO_HANDSHAKE, gpio_handshake_isr_handler, NULL);

    // Initialize the SPI bus and add the device we want to send stuff to.
    ret = spi_bus_initialize(SENDER_HOST, &buscfg, SPI_DMA_CH_AUTO);
    assert(ret == ESP_OK);
    ret = spi_bus_add_device(SENDER_HOST, &devcfg, &handle);
    assert(ret == ESP_OK);

    // Assume the slave is ready for the first transmission: if the slave started up before us, we will not detect
    // positive edge on the handshake line.
    xSemaphoreGive(rdySem);

    while (1)
    {
        int res = snprintf(sendbuf, sizeof(sendbuf),
                           "Sender, transmission no. %04i. Last time, I received: \"%s\"", n, recvbuf);
        // Check if the data was truncated
        if (res >= sizeof(sendbuf))
        {
            // Print a warning if the data was truncated
            printf("Data truncated\n");
        }
        t.length = sizeof(sendbuf) * 8; // Set the length of the SPI transaction (in bits)
        t.tx_buffer = sendbuf;
        t.rx_buffer = recvbuf;
        // Wait for slave to be ready for next byte before sending
        xSemaphoreTake(rdySem, portMAX_DELAY); // Wait until slave is ready
        ret = spi_device_transmit(handle, &t);
        printf("Received: %s\n", recvbuf);
        n++;
    }

    // Never reached.
    ret = spi_bus_remove_device(handle);
    assert(ret == ESP_OK);
}

```
