#### 写设置
* 24C02 EEPROM的I2C地址通常是0x50。但是，这可能会根据具体的硬件设计或配置有所不同。在某些情况下，可以通过设置A0、A1和A2引脚来改变设备的I2C地址。这些引脚通常用于在同一I2C总线上连接多个24C02设备。
* 在写入操作中，设备地址后面通常会跟着一个内存地址，这是你要写入数据的EEPROM内存位置。
* 24C02的基础I2C地址是0x50。A0、A1和A2引脚用于修改这个基础地址。每个引脚都对应一个二进制位，A2是最高位，A0是最低位。
* 因此，如果A0设置为1，A1和A2设置为0，那么这将在基础地址上增加1，因此设备的I2C地址将会是0x51。
* 写周期：5ms
* 页大小：32byte
