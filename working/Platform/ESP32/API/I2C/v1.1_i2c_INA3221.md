##### 可能发生的内存泄露
* 每次读取传感器数据时，都会创建一个新的I2C命令链接（`i2c_cmd_link_create`），但在读取完成后，只有在出现错误时才会删除这个链接（`i2c_cmd_link_delete`）。如果在读取过程中没有出现错误，那么这个链接就不会被删除，可能会导致内存泄漏。
```  c++
// Read bus voltage
    cmd = i2c_cmd_link_create();
    ret = i2c_master_read_from_reg(cmd, INA3221_SENSOR_ADDR, REG_BUS_VOLTAGE_CHANNEL1 + i * 2, &data_h, &data_l);
    rawVoltage = (data_h << 8) | data_l;        // Combine high byte and low byte
    bus_voltage[i] = (rawVoltage >> 3) * 0.008; // Multiply by 8mV to get the actual voltage
    if (ret != ESP_OK)
    {
        i2c_cmd_link_delete(cmd); // Delete the cmd link only if there was an error
    }
```

解决办法 ：Always delete the cmd link after reading

#### 通道三的电压会逐渐降低
* 可能的情况是通道三的分流电阻R43在5v电压下出现发热，导致阻值出现变化，影响结果

#### tips
* 所有数据字节均MSB优先传输
* P-高侧，N-低侧
* INA3221是一款三通道的高侧电流和总线电压监测器，具有与I2C和SMBUS兼容的接口。可监测分流电压降和总线供电电压
#### MSB LSB

MSB：高字节优先，也叫大端字节序，即在多字节数据类型中，最高有效字节（即数值最大的字节）放在最低地址处。

`rawVoltage = (data_h << 8) | data_l`

##### R42,R43--提供参考电压，校准INA3221内部增益和偏移

可以把 R42 和 R43 看成是一个分压器，它们把 +3.3V 的电压分成两半，即 1.65V，然后输入到 INA3221 的内部。INA3221 会用这个参考电压来校准它的内部增益和偏移，使得它能更准确地测量分流电压和总线电压。

##### C21--对分流电压进行低通滤波，去除高频噪声

可以把 C21 看成是一个阻抗，它的阻抗大小与频率有关。当频率很低时，C21 的阻抗很大，相当于一个开路；当频率很高时，C21 的阻抗很小，相当于一个短路。 因此，当我们测量分流电压时，我们只关心低频信号，即直流信号或者慢变化的交流信号。这些信号对 C21 来说是开路，所以 C21 对它们没有影响。只有高频信号，即快变化的交流信号或者噪声信号，对 C21 来说是短路，所以 C21 会把它们滤掉。

##### 总线电压

* 对于总线电压，INA3221的测量范围是0-26V，其测量值被放大8倍后存储在寄存器中。因此，为了获取真实的总线电压值，我们需要将寄存器中的值右移3位（即除以8）。这可以通过以下公式完成：
```
bus_voltage = (rawVoltage >> 3) * 0.008
```
* 通道1,2的总线电压为3.3v,通道3的总线电压为5.0v。

##### 分线电压/电流

* 分线电压的实际值可以通过以下公式转换得到：
```
bus_voltage = (rawVoltage >> 3) * 0.008
``` 

* R42、R43、C21 对分流电压的影响是很小的，可以忽略不计。所以，在计算分流电流的时候，只需要使用通道 1 的分流电压除以 R41 的阻值 100 欧姆就可以了。
##### 功率

* 使用总线电压和通过分线电阻的电流来计算功率
* 如果你使用分线电压来计算功率，那么你计算出来的将是通过分线电阻的功率，而不是整个设备或电路的功率。

### 警报功能

* 为 INA3221 的 16 号引脚 ALERT 外接一个上拉电阻到 VPU 引脚。VPU 引脚可以接到 VS 或其他电源上，但不能超过 VS +0.3 V。ALERT 是一个**开漏输出**，所以需要外接上拉电阻才能输出高低电平。
* 通过 I2C 或 SMBUS 接口编程设置 INA3221 的**警报模式**、**临界阈值**和**预警阈值**。INA3221 有多个寄存器可以用来设置这些参数 。
* 将 INA3221 的 16 号引脚` ALERT `连接到 ESP32C6 主控的一个数字输入引脚上，用于读取 INA3221 的警报信号。也可以将 ALERT 引脚连接到其他设备上，例如 LED、蜂鸣器、继电器等，用于输出可视或者可听的警报信号。
#### code
```c++
// 在INA3221上配置警报参数
i2c_write_register(INA3221_I2C_ADDRESS, INA3221_ALERT_CONFIG_REGISTER, alert_threshold);

// 在INA3221上启用警报功能
i2c_write_register(INA3221_I2C_ADDRESS, INA3221_ALERT_ENABLE_REGISTER, ENABLE_VALUE);

// 设置一个中断服务例程来处理警报信号
void alert_isr() {
    // 当触发警报时执行的代码
}

// 配置你的微控制器的中断引脚，当ALERT引脚变高时触发ISR
configure_interrupt_pin(ALERT_PIN, alert_isr);
```
* i2c_write_register`是一个函数，用于向I2C设备的特定寄存器写入值。
* INA3221_I2C_ADDRESS`是你的INA3221设备的I2C地址，
* INA3221_ALERT_CONFIG_REGISTER`和`INA3221_ALERT_ENABLE_REGISTER`是控制警报功能的寄存器，
* alert_threshold`和`ENABLE_VALUE`是要写入这些寄存器的值。`
* configure_interrupt_pin`是一个函数，用于配置微控制器上的引脚，使其在状态改变时触发中断服务例程。

```c++
#include <stdio.h>
#include "esp_log.h"
#include "driver/i2c.h"
#include "sdkconfig.h"

static const char *TAG = "V1.1_i2c_INA3221";

#define I2C_MASTER_PORT_NUM 0

#define DATA_LENGTH 512                  /*!< Data buffer length of test buffer */
#define RW_TEST_LENGTH 128               /*!< Data length for r/w test, [0,DATA_LENGTH] */
#define DELAY_TIME_BETWEEN_ITEMS_MS 1000 /*!< delay time between different test items */

#define I2C_MASTER_SCL_IO GPIO_NUM_7       /*!< gpio number for I2C master clock */
#define I2C_MASTER_SDA_IO GPIO_NUM_6       /*!< gpio number for I2C master data  */
#define I2C_MASTER_NUM I2C_MASTER_PORT_NUM /*!< I2C port number for master dev */
#define I2C_MASTER_FREQ_HZ 100000          /*!< I2C master clock frequency */
#define I2C_MASTER_TX_BUF_DISABLE 0        /*!< I2C master doesn't need buffer */
#define I2C_MASTER_RX_BUF_DISABLE 0        /*!< I2C master doesn't need buffer */

#define INA3221_SENSOR_ADDR 0x40      // Define the I2C address for the INA3221 sensor
#define REG_BUS_VOLTAGE_CHANNEL1 0x02 // Register address for Bus Voltage
#define REG_BUS_VOLTAGE_CHANNEL2 0x04 // Register address for Bus Voltage of channel 2
#define REG_BUS_VOLTAGE_CHANNEL3 0x06 // Register address for Bus Voltage of channel 3
#define REG_SHUNT_VOLT_CHANNEL1 0x01  // Register address for Shunt Voltage of channel 1
#define REG_SHUNT_VOLT_CHANNEL2 0x03  // Register address for Shunt Voltage of channel 2
#define REG_SHUNT_VOLT_CHANNEL3 0x05  // Register address for Shunt Voltage of channel 3

#define WRITE_BIT I2C_MASTER_WRITE /*!< I2C master write */
#define READ_BIT I2C_MASTER_READ   /*!< I2C master read */
#define ACK_CHECK_EN 0x1           /*!< I2C master will check ack from slave */
#define ACK_CHECK_DIS 0x0          /*!< I2C master will not check ack from slave */
#define ACK_VAL 0x0                /*!< I2C ack value */
#define NACK_VAL 0x1               /*!< I2C nack value */

static esp_err_t i2c_master_read_from_reg(i2c_cmd_handle_t cmd, uint8_t device_addr, uint8_t reg_addr, uint8_t *data_h, uint8_t *data_l)
{
    esp_err_t ret;
    i2c_master_start(cmd);
    i2c_master_write_byte(cmd, (device_addr << 1) | WRITE_BIT, ACK_CHECK_EN);
    i2c_master_write_byte(cmd, reg_addr, ACK_CHECK_EN);
    i2c_master_start(cmd);
    i2c_master_write_byte(cmd, (device_addr << 1) | READ_BIT, ACK_CHECK_EN);
    i2c_master_read_byte(cmd, data_h, ACK_VAL);
    i2c_master_read_byte(cmd, data_l, NACK_VAL);
    i2c_master_stop(cmd);
    ret = i2c_master_cmd_begin(I2C_MASTER_NUM, cmd, 1000 / portTICK_PERIOD_MS);
    return ret;
}

static esp_err_t i2c_master_sensor_test(i2c_port_t i2c_num, double bus_voltage[3], double shunt_voltage[3])
{
    int ret;
    uint8_t data_h = 0, data_l = 0;
    uint16_t rawVoltage;
    i2c_cmd_handle_t cmd;

    // Read bus voltage and shunt voltage for each channel
    for (int i = 0; i < 3; i++)
    {
        // Read bus voltage
        cmd = i2c_cmd_link_create();
        ret = i2c_master_read_from_reg(cmd, INA3221_SENSOR_ADDR, REG_BUS_VOLTAGE_CHANNEL1 + i * 2, &data_h, &data_l);
        rawVoltage = (data_h << 8) | data_l;        // Combine high byte and low byte
        bus_voltage[i] = (rawVoltage >> 3) * 0.008; // Multiply by 8mV to get the actual voltage
        i2c_cmd_link_delete(cmd);                   // Always delete the cmd link after reading

        // Read shunt voltage
        cmd = i2c_cmd_link_create();
        ret = i2c_master_read_from_reg(cmd, INA3221_SENSOR_ADDR, REG_SHUNT_VOLT_CHANNEL1 + i * 2, &data_h, &data_l);
        rawVoltage = (data_h << 8) | data_l; // Combine high byte and low byte
        if (rawVoltage & 0x8000)
        {                             // If the most significant bit is set
            rawVoltage |= 0xFFFF0000; // Extend the sign bit
        }
        shunt_voltage[i] = (rawVoltage)*0.00004; // Convert raw shunt voltage to actual voltage
        i2c_cmd_link_delete(cmd);                // Always delete the cmd link after reading，
    }

    return ESP_OK;
}

/**
 * @brief i2c master initialization
 */
static esp_err_t i2c_master_init(void)
{
    int i2c_master_port = I2C_MASTER_NUM; // Define the I2C master port number
    i2c_config_t conf = {
        .mode = I2C_MODE_MASTER,                // Set the I2C mode as master
        .sda_io_num = I2C_MASTER_SDA_IO,        // Set the SDA pin number
        .sda_pullup_en = GPIO_PULLUP_ENABLE,    // Enable the pull-up resistor for SDA pin
        .scl_io_num = I2C_MASTER_SCL_IO,        // Set the SCL pin number
        .scl_pullup_en = GPIO_PULLUP_ENABLE,    // Enable the pull-up resistor for SCL pin
        .master.clk_speed = I2C_MASTER_FREQ_HZ, // Set the clock speed for I2C communication
        // .clk_flags = 0,          /*!< Optional, you can use I2C_SCLK_SRC_FLAG_* flags to choose i2c source clock here. */
    };
    esp_err_t err = i2c_param_config(i2c_master_port, &conf); // Configure I2C parameters
    if (err != ESP_OK)
    { // Check if configuration was successful
        return err;
    }
    return i2c_driver_install(i2c_master_port, conf.mode, I2C_MASTER_RX_BUF_DISABLE, I2C_MASTER_TX_BUF_DISABLE, 0); // Install I2C driver
}

    int task_idx = (int)arg;
    int cnt = 0;
    int ret;
    double bus_voltage[3], shunt_voltage[3];
    double shunt_resistance = 100.0;
    double current[3];
    double power[3];
    while (1)
    {
        ESP_LOGI(TAG, "TASK[%d] test cnt: %d", task_idx, cnt++);                    // Print task information
        ret = i2c_master_sensor_test(I2C_MASTER_NUM, &bus_voltage, &shunt_voltage); // Call the new function to read the INA3221's data
        // xSemaphoreTake(print_mux, portMAX_DELAY);

        {
            ESP_LOGE(TAG, "I2C Timeout"); // Print error message if I2C timeout occurs
        }
        else if (ret == ESP_OK)
        {
            printf("*******************\n");
            printf("TASK[%d]  MASTER READ SENSOR(IAN3221)\n", task_idx); // Print sensor read operation information
            printf("*******************\n");
            for (int i = 0; i < 3; i++)
            {
                current[i] = shunt_voltage[i] / shunt_resistance;
                power[i] = bus_voltage[i] * current[i];
                printf("bus_voltage[%d]   : %.06lf [V]\n", i, bus_voltage[i]);   // Print the actual voltage
                printf("shunt_voltage[%d] : %.06lf [V]\n", i, shunt_voltage[i]); // Print the actual voltage
                printf("current[%d]       : %.06lf [A]\n", i, current[i]);       // Print the actual voltage
                printf("power[%d]         : %.06lf [W]\n\n", i, power[i]);         // Print the actual voltage
            }
        }
        else
        {
            ESP_LOGW(TAG, "%s: No ack, sensor not connected...skip...", esp_err_to_name(ret)); // Print warning message if no acknowledgement is received
        }
        // xSemaphoreGive(print_mux);
        vTaskDelay((DELAY_TIME_BETWEEN_ITEMS_MS * (task_idx + 1)) / portTICK_PERIOD_MS); // Delay between different test items
        //---------------------------------------------------
    }

}
```
