## `USART-HMI`

- 选择`bt`双态按钮作为`led`
- `UTF-8`
	英文字符一个字节，中文字符三个字节
	目前拼音输入法键盘只有工程和字库编码均为`GB2312`才能正常使用
- `sys`
	`sys0-sys2`是生成工程时默认可以使用变量，可以模仿int定义的写法来创建自己的变量，`program.s`中创建的变量均为全局变量。

- `spstr` 添加空格
- `pic`-刷图指令
	在当前页面进行刷图，不支持跨页面刷图，不能写在页面的前初始化事件中
	图片控件和图片id并不需要一一对应，一个图片控件可以对应多个图片id,实现循环播放
	在坐标(10,20)位置显示资源文件中图片ID为0的图片
```c
 pic 10,20,0
```

 - 心跳动画
```c
if(va0.val==1&&p0.pic<30)
{
  p0.pic++
}else
{
  va0.val=0
  p0.pic--
}
if(p0.pic==0)
{
  va0.val=1
}
```
### 无效指令
- 符号两边 `=`两边不要有**空格**
```c
if(p0.pic==1)  //正确
if(p0.pic == 1)//错误
```
- 未指定控件的具体属性，结尾有分号
- `to.txt="123\n456`,转义字符使用错误，换行用`\r`
- `if` `while` 判断中不要进行**运算**，不要**嵌套括号**，必须有大括号且必须单独占一行

### 跨页面赋值
- 首先需要将该控件属性设置为全局类型
- `[页面].[控件].[属性]=XXX`
```C
main.t0.txt="123"
main.t0.txt=set.t3.txt
set.t4.txt="abc"
page2.va1.val=5
```
`！注意事项`
- 跨页面操作控件属性时，不论读取还是赋值，被操作控件的`vscope`属性必须设置为全局
- `click` `vis` `tsw`指令无法跨页面触发控件、定时器控件只能在当前页面运行、曲线波形控件只能在当前页面添加数据点
### 名称组
- 格式：` p[页面DP号].b[控件ID].属性`
- p是`page`（页面）的缩写，b是`objec`t（对象）的缩写，而不是指`button`（按钮），名称组访问控件，只有控件`id`的概念，没有控件类型的概念
### `RTC`
- 需要纽扣电池
## `MCU`
- 单片机通过串口给图片控件赋值
```c
	//让图片控件p0显示id为0的图片
	printf("p0.pic=0\xff\xff\xff");
	
	//让图片控件p1显示id为1的图片
	printf("p1.pic=%d\xff\xff\xff",a);
```

- 单片机通过串口在坐标(40,50)位置显示资源文件中图片ID为1的图片
```c
 int posX=40, posY=50, pic=1;
 printf("pic %d,%d,%d\xff\xff\xff", posX, posY, pic);
```

- 清空屏幕接收缓冲区
```c
printf("\x00\xff\xff\xff");
```
