有许多协议依赖于TCP（Transmission Control Protocol，传输控制协议）来传输数据。TCP提供了一种可靠的面向连接的服务，使得这些协议能够在互联网上稳定地工作。下面是一些常用的依赖TCP的协议及其默认端口号：

1. **HTTP (Hypertext Transfer Protocol)**
   - **端口号**：80 (非加密 HTTP)
   - **端口号**：443 (HTTPS, 加密 HTTP)

2. **FTP (File Transfer Protocol)**
   - **端口号**：20 (数据传输)
   - **端口号**：21 (控制连接)

3. **SMTP (Simple Mail Transfer Protocol)**
   - **端口号**：25 (邮件发送)
   - **端口号**：465 (SSL 加密 SMTP)
   - **端口号**：587 (提交邮件)

4. **POP3 (Post Office Protocol Version 3)**
   - **端口号**：110 (未加密 POP3)
   - **端口号**：995 (SSL 加密 POP3)

5. **IMAP (Internet Message Access Protocol)**
   - **端口号**：143 (未加密 IMAP)
   - **端口号**：993 (SSL 加密 IMAP)

6. **Telnet**
   - **端口号**：23 (未加密 Telnet)
   - **端口号**：2323 (有时用于替代端口)

7. **SSH (Secure Shell)**
   - **端口号**：22 (加密 SSH 会话)

8. **DNS (Domain Name System)**
   - **端口号**：53 (虽然 DNS 通常使用 UDP 协议，但它也可以使用 TCP)

9. **LDAP (Lightweight Directory Access Protocol)**
   - **端口号**：389 (未加密 LDAP)
   - **端口号**：636 (SSL 加密 LDAP)

10. **SMB/CIFS (Server Message Block/Common Internet File System)**
    - **端口号**：445 (SMB/CIFS)

11. **NTP (Network Time Protocol)**
    - **端口号**：123 (虽然 NTP 通常使用 UDP 协议，但也可以使用 TCP)

### 注意

- 许多协议都有默认的端口号，但这些端口号可以被重新配置。
- 服务器通常监听这些默认端口来提供服务。
- 客户端通常使用这些端口来发起连接请求。
- 端口号在0-1023之间被称为“熟知端口”或“注册端口”，通常用于系统级服务。
- 端口号1024-49151被称为“注册端口”，可以由应用程序注册使用。
- 端口号49152-65535被称为“动态或私有端口”，通常用于临时客户端端口。

这些协议和端口号在实际部署中可能会有所不同，具体取决于网络配置和服务提供商的要求。
