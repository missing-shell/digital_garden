### WebSocket 协议简介

WebSocket 是一种在单个持久连接上进行全双工通信的协议。它提供了在客户端和服务器之间进行低延迟、高带宽通信的能力，非常适合实时应用。

### WebSocket 的特点

1. **全双工通信**：
   - WebSocket 支持客户端和服务器之间的双向通信，双方都可以随时发送数据。

2. **低延迟**：
   - 由于使用了持久连接，WebSocket 可以提供更低的延迟，非常适合实时通信。

3. **持久连接**：
   - WebSocket 连接建立后，客户端和服务器之间维持一个持久的连接，直到一方显式关闭连接。

4. **文本或二进制数据**：
   - WebSocket 支持发送文本数据（UTF-8 编码）和二进制数据。

5. **多路复用**：
   - WebSocket 连接可以承载多个通信通道，允许多个独立的数据流共享同一个连接。

6. **安全连接**：
   - WebSocket 支持通过TLS/SSL进行加密通信，使用wss:// URL方案。

### WebSocket 的工作流程

1. **握手**：
   - 客户端通过HTTP发起一个特殊的GET请求到服务器，请求升级为WebSocket连接。
   - 服务器响应Upgrade头，确认连接升级为WebSocket。

2. **数据交换**：
   - 连接建立后，客户端和服务器可以通过WebSocket连接发送和接收数据。
   - 数据可以是文本或二进制形式。

3. **关闭连接**：
   - 任一方可以发送关闭帧来关闭连接。
   - 关闭帧包含一个状态码和可选的原因字符串。

### WebSocket 的使用场景

1. **实时聊天应用**：
   - 实时聊天需要低延迟的通信，WebSocket 是理想的选择。

2. **在线游戏**：
   - 游戏需要快速响应用户输入，WebSocket 提供了必要的低延迟。

3. **实时数据分析**：
   - 如股票市场分析、传感器数据流等需要实时更新的应用。

4. **远程控制和协作**：
   - 如在线协作编辑文档、远程桌面控制等。

5. **物联网(IoT)**：
   - IoT 应用需要设备与服务器之间的实时通信。

### WebSocket 的端口号

WebSocket 默认使用与HTTP相同的端口：
- **HTTP**：80 (非加密)
- **HTTPS**：443 (加密)

对于WebSocket连接，URL方案分别为：
- **ws://** (非加密)
- **wss://** (加密)
