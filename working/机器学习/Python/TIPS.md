- assert
	通常python运行在调试模式，程序中的断言语句可以帮助程序调错
	正式运行时，使用运行选项-O，以优化模式运行来禁用断言，从而提高程序效率
```python
 python assert.py
 python –O assert.py
```

- `print(("*"*n)`
	`*n`代表要输出的输出的星号(`*`)的数量

- 在python中，一个函数无法改变一个不可变对象的(整数，浮点数，布尔值或字符串的值)即函数无法产生副作用
	如果函数体中修改对象的值，其结果实际上是创建了一个新的对象

- 字典（dictionary）
    - 字典（dictionary）是一种可变容器模型，且可存储任意类型对象。字典的每个键值对（key-value pair）用冒号(:)分割，每个对之间用逗号(,)分割，整个字典包括在花括号({})中。
    - 键（Key）：字典中的键必须是唯一的。键可以是任意不可变类型，如字符串、数字或元组。
   -  值（Value）：字典中的值没有唯一性要求，值可以取任何数据类型，且可以重复。
   - 在字典的键值对中，冒号左边的部分总是键，右边的部分总是值。

- 全局变量
	在函数体中，可以引用全局变量，但如果函数内部的变量名是第一次出现且在赋值语句之前（变量赋值），则解释为定义局部变量
```python
m = 100
n = 200
def f():
    print(m+5)  #引用全局变量m
    n += 10 #错误，n在赋值语句前面，解释为局部变量（不存在）
#测试代码
f()
```
