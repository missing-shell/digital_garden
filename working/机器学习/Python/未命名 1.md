# 游标
* 根据数据库的官方定义，游标（cursor）是一个数据库查询的关键组成部分，它可以用于从数据库中获取数据，也可以用来识别需要更新或删除的表中的行。

* 在数据库中，游标是一个控制结构，用于管理在数据库查询返回的行集（也称为结果集）之间的移动。游标允许你从一个大的结果集中一次处理一行数据，这使得你可以对每一行数据进行更复杂的处理，而不是一次性处理整个结果集。游标也可以用于更新和删除表中的行。

* 在很多数据库系统（如MySQL，PostgreSQL，SQL Server，Oracle等）中，你可以声明一个游标，并使用FETCH命令来检索结果集中的行。你也可以使用UPDATE或DELETE命令，配合WHERE CURRENT OF cursor_name子句，来更新或删除由游标指向的当前行。

* 在Python的sqlite3模块中，游标对象（cursor object）提供了一个执行SQL命令和处理结果集的接口。你可以使用游标对象的execute()方法来执行SQL命令，然后使用fetchone()或fetchall()方法来获取结果集。

**实际上，在SQLite中存储的数据可以是任何类型，SQLite不会强制检查数据类型。这意味着你可以在INTEGER字段中存储文本，或者在TEXT字段中存储数字。但这样做可能会导致数据混乱，不推荐这样做。**
