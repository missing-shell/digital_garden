- 在 python 中，所有的类都是 type 类型
- 两个下划线开头，但是不以两个下划线结束的属性是私有的（private），其他为公共的（public）
- 私有属性：只能在类的内部访问
## 实例对象和类

- 如果`get_count`方法不需要访问实例对象的任何属性或方法，你可以将它定义为类方法或静态方法。类方法和静态方法都可以通过类名或实例对象来调用，但是它们不接受`self`参数。
- 实例对象可以访问类的所有方法，但是这些方法必须至少接受一个参数，通常命名为`self`，代表实例对象本身。
- 类的实例对象可以访问类的方法，但是类不能直接访问类实例对象的方法。
## 继承

- 声明派生类时，必须在其构造函数中调用基类的构造函数
- 通过继承，派生类继承基类中除构造方法之外的所有成员
- 如果在派生类中重新定义从基类继承的方法，则派生类中定义的方法覆盖从基类中继承的方法
