 对称密钥加密算法（如**AES**）是由数学家和密码学家设计的，其想法是，在没有加密密钥的情况下**解密密文是不可行的**。这对于现代**安全对称加密算法（如 AES 和 ChaCha20）来说是正确的，但对于其他被认为是****不安全对称加密算法**（如 DES 和 RC4）的算法来说可能是有争议的或错误的。

一些流行的对称加密算法有：**AES**、**ChaCha20**、**CAST**、**Twofish**、**IDEA**、**Serpent**、**RC5**、**RC6**、**Camellia**和**ARIA**。所有这些算法都被认为是**安全的**（当正确配置和使用时）。

## AES（**Rijndael）**

[**AES**](https://en.wikipedia.org/wiki/Advanced_Encryption_Standard)（**高级****加密**标准**，**又称**Rijndael**）是现代IT行业、**应用最广泛的对称加密算法**。这是因为 AES 被证明是**高度安全**、快速且标准化良好的，并且几乎在所有平台上都得到很好的支持。 AES 是 128 位**分组密码**，使用 128、192 或 256 位密钥。它通常用于像**AES-CTR**或**AES-GCM那样的****块模式**来处理流数据。在大多数块模式中，AES 还需要一个随机的 128 位初始向量（IV，nonce）。

**Rijndael是**[NIST 组织的 AES 竞赛](https://en.wikipedia.org/wiki/Advanced_Encryption_Standard_process)（1997-2000）的获胜者，并以“ **AES** ”（继 DES 后的下一个官方对称分组密码）的名称正式宣布。 2001 年，AES 被**美国政府**采纳为官方推荐，此后没有发现重大弱点或攻击。

Rijndael (AES) 算法**对任何用途都是免费的**：公共或私人、商业或非商业。

## 莎莎20 / ChaCha20**

[**Salsa20**](https://en.wikipedia.org/wiki/Salsa20)及其改进变体**ChaCha**（ **ChaCha8**、 **ChaCha12**、 **ChaCha20**）和**XSalsa20**是现代、快速、**对称流密码系列，由杰出的密码学家**[Daniel Bernstein](https://en.wikipedia.org/wiki/Daniel_J._Bernstein)设计。 **Salsa20**密码[是eSTREAM](https://en.wikipedia.org/wiki/ESTREAM)新型对称流密码设计竞赛（2004-2008 年）的决赛入围者之一**，随后与相关的BLAKE**哈希函数一起被广泛采用。 **Salsa20**及其变体是**免版税的**，没有专利。

**Salsa20**密码将**128 位**或**256 位对称密钥**+ 随机生成的**64 位随机数**（初始向量）和无限长度的数据流作为输入，并生成与以下长度相同的加密数据流作为输出输入流。 Salsa20 密码通常用作经过身份验证的加密结构：[**ChaCha20-Poly1305**](https://tools.ietf.org/html/rfc7539)。

## 其他流行的对称密码

其他**现代安全对称密码**比 EAS 和 ChaCha20 使用较少，但在软件开发人员和信息安全社区中仍然很流行，如下所示：

- [**Serpent**](https://en.wikipedia.org/wiki/Serpent_%28cipher%29) - 安全对称密钥分组密码（密钥大小：128、192 或 256 位），公共领域，未申请专利
    
- [**Twofish**](https://en.wikipedia.org/wiki/Twofish) - 安全对称密钥分组密码（密钥大小：128、192 或 256 位），免版税，未申请专利
    
- [**Camellia**](https://en.wikipedia.org/wiki/Camellia_%28cipher%29) - 安全对称密钥块密码（块大小：128 位；密钥大小：128、192 和 256 位），已获得专利，但免费用于非商业用途
    
- [**RC5**](https://en.wikipedia.org/wiki/RC5) - 安全对称密钥分组密码（密钥大小：128 至 2040 位；块大小：32、64 或 128 位；轮数：1 ... 255），短密钥不安全（56 位密钥成功暴力破解） ，已获得专利直至 2015 年，现在免版税
    
- [**RC6**](https://en.wikipedia.org/wiki/RC6) - 安全对称密钥分组密码，与 RC5 类似，但更复杂（密钥大小：128 至 2040 位；块大小：32、64 或 128 位；轮数：1 ... 255），现已获得专利，直至 2017 年免版税
    
- [**IDEA**](https://en.wikipedia.org/wiki/International_Data_Encryption_Algorithm) - 安全对称密钥分组密码（密钥大小：128 位），2012 年之前获得专利，现在免版税
    
- [**CAST**](https://en.wikipedia.org/wiki/CAST-256) ( [CAST-128 / CAST5](https://en.wikipedia.org/wiki/CAST-128) , [CAST-256 / CAST6](https://en.wikipedia.org/wiki/CAST-128) ) - 安全对称密钥分组密码系列（密钥大小：40 ... 256 位），商业和非商业用途免版税
    
- [**ARIA**](https://en.wikipedia.org/wiki/ARIA_%28cipher%29) - 安全对称密钥分组密码，类似于 AES（密钥大小：128、192 或 256 位），韩国官方标准，免费供公众使用
    
- [**SM4**](https://en.wikipedia.org/wiki/SM4_%28cipher%29) - 安全对称密钥分组密码，类似于 AES（密钥大小：128 位），中国官方标准，免费供公众使用
    

## 不安全的对称算法

其他一些对称加密算法过去很流行，但现在被认为**不安全（损坏的算法）**或**安全性有争议**，**不建议**再使用：

- [**DES**](https://en.wikipedia.org/wiki/Data_Encryption_Standard) - 56 位密钥大小，几乎已被破解，可以被暴力破解
    
- [**3DES**](https://en.wikipedia.org/wiki/Triple_DES)（三重 DES）- 64 位密码，被认为已损坏
    
- [**RC2**](https://en.wikipedia.org/wiki/RC2) - 64 位密码，被认为已损坏
    
- [**RC4**](https://en.wikipedia.org/wiki/RC4) - 流密码、已破解的实际攻击演示
    
- [**Blowfish**](https://en.wikipedia.org/wiki/Blowfish_%28cipher%29) - 旧的 64 位密码、已损坏的实际攻击演示
    
- [**GOST**](https://en.wikipedia.org/wiki/GOST_%28block_cipher%29) - 俄罗斯 64 位分组密码，安全性有争议，被认为有风险
    

## 对称加密方案/结构

除了上述对称密钥密码之外，密码学家还提出了许多**对称加密方案**（构造），例如最流行的认证加密（AEAD）方案：

- [**ChaCha20-Poly1305**](https://tools.ietf.org/html/rfc7539)
    
    - 带有集成**Poly1305验证器的****ChaCha20**流密码（集成验证 AEAD 加密）
        
    - 需要**256 位密钥**和随机**96 位随机数**
        
    - 极高**的性能**
        
    - 由最现代的加密库实施
        
    
- [**AES-256-GCM**](https://tools.ietf.org/html/rfc5288)
    
    - **AES-GCM**是 GCM 块模式下的 AES (Rijndael) 块密码（集成认证 AEAD 加密），其行为类似于流密码
        
    - 所需的**256 位密钥**和随机**128 位随机数**（初始向量）
        
    - 由最现代的加密库实现
        

**ChaCha20-Poly1305**是高性能密码（在移动设备上比 AES-128-GCM[快 3 倍](https://www.imperialviolet.org/2014/02/27/tlssymmetriccrypto.html)），因此建议**使用**它来代替 AES-GCM。
