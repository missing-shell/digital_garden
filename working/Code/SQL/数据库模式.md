* 数据库的模式是指数据库中数据的逻辑结构和特征的描述，是所有用户的公共数据视图
- **外模式**：也叫子模式或用户模式，是数据库用户能够看见和使用的局部数据的逻辑结构和特征的描述，是用户与数据库系统之间的接口。不同的用户可以有不同的外模式，以满足各自的需求。
- **概念模式**：也叫逻辑模式，是数据库中全体数据的逻辑结构和特征的描述，是所有用户的公共数据视图。它反映了数据之间的关系和约束条件，但不涉及具体的存储方式。
- **内模式**：也叫存储模式或物理模式，是数据在数据库中的物理表示方式和存储结构的描述 。它包括数据的存储空间分配、记录的存储方式、索引的组织等。

* 这三种模式之间通过两级映射建立联系，分别是**外模式/概念模式映射**和**概念模式/内模式映射**。这样可以保证**数据的逻辑独立性和物理独立性**，即当数据的物理组织或逻辑结构发生变化时，不影响用户对数据的使用
