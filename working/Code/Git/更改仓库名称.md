## 1. **更改本地仓库目录名**：
首先，在本地文件系统中将包含仓库的目录重命名为您希望的新名称。打开命令行或终端，进入包含仓库的上级目录，然后执行重命名操作。例如，如果原仓库名为 `old-repo`，新仓库名应为 `new-repo`，则执行：

```shell
mv old-repo new-repo
```

2. **更新本地仓库配置**： 进入新命名的仓库目录，打开Git Bash（Windows）或终端（Unix/Linux/MacOS），并更新仓库的远程URL。首先，查看当前的远程URL：

 ```bash
 git remote -v
 ```

输出将显示当前远程仓库的URL。找到与原仓库名对应的URL，通常为 `origin`。然后，使用 `git remote set-url` 命令更新该URL中的仓库名称：

```bash
 git remote set-url origin https://github.com/your-username/new-repo.git
```

或者，如果您使用的是SSH方式：

bash

   `git remote set-url origin git@github.com:your-username/new-repo.git`

请确保将上述命令中的 `your-username` 和 `new-repo` 替换为您的GitHub用户名和新仓库名。

3. **在GitHub上创建新仓库（如果尚未创建）**： 如果您尚未在GitHub上创建名为 `new-repo` 的新仓库，请访问GitHub网站，登录后按照以下步骤操作：

    a. 点击右上角的"+"按钮，选择 "New repository"。 b. 输入新仓库名 `new-repo`，设置描述和其他选项（如是否公开、添加README等），然后点击 "Create repository"。

4. **推送本地变更到新仓库**： 在本地命令行中，将本地分支内容推送到新命名的远程仓库：

bash

   `git push -u origin main`

如果您的默认分支不是 `main`，请替换为实际的默认分支名（如 `master`）。

至此，您已成功将本地Git仓库名称更改为 `new-repo`，并将其与GitHub上的同名仓库关联。后续的Git操作可直接在新命名的本地仓库及其关联的远程仓库进行。
