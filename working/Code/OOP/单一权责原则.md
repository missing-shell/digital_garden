# 编程规范

## 1.函数和类

### 1.1单一权责原则

在面向对象编程领域中，单一权责原则规定每个类都应该有一个单一的功能，并且该功能应该有这个类完全封装起来。一个类或者模块应该有且只有一个可以改变的原因。

### 1.2尽量不要在参数中传递状态值

状态值是函数做了多件事的明显标志。

将原本的setLoading函数分解成了两个更具体的函数：showLoading和hideLoading。这样做的好处是可以提高代码的可读性和可维护性。

```c
fun setLoading(status: Boolean) {
    if (status) {
       loading.visibility = View.VISIBLE
    } else {
        loading.visibility = View.GONE
    }
}
修改为：
fun showLoading() {
    loading.visibility = View.VISIBLE
}

fun hideLoading() {
    loading.visibility = View.GONE
}

```

### 1.3 同一函数中的代码应该属于同一层级

分离位于不同层级的代码 ，较低层级概念和较高层级概念不应该混杂在一起。
