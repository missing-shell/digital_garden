# 枚举 前缀和 双指针

## 暴力枚举

- 使用**二维前缀和**处理初始矩阵
- 四重循环枚举每个前缀和矩阵
- 时间复杂度：$O(n^4)$

二维前缀和

```c++
 for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            scanf("%d", &ans[i][j]);
            s[i][j] = (s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + ans[i][j]);
        }
    }
```

暴力枚举

```c++
 LL res = 0;

    for (int x1 = 1; x1 <= n; x1++)
    {
        for (int y1 = 1; y1 <= m; y1++)
        {
            for (int x2 = x1; x2 <= n; x2++)//下边界必定大于等于上边界,1X1也可以  `x2=x1`
            {
                for (int y2 = y1; y2 <= m; y2++)
                {
                    int sum = s[x2][y2] - s[x1 - 1][y2] - s[x2][y1 - 1] + s[x1 - 1][y1 - 1];
                    if (sum <= k)
                    {
                        res++;
                    }
                }
            }
        }
    }
```

## 优化暴力枚举部分

- 参考： [travis73题解](https://www.acwing.com/solution/content/110471/)
- 时间复杂度：$O(n^3)$
- 使用**双指针**优化四重枚举
 枚举子矩阵的左边界`i`和右边界`j`

 将行看作一个一个整体，使用快指针`r`枚举子矩阵的下边界，慢指针`s`维护子矩阵的上边界`(s<=t)`    （或者将列看作一个整体）

 如果子矩阵权值大于`K`,则**慢指针前进，而子矩阵和必将单调不增**

 慢指针继续前进直到子矩阵权值和`<=k`,此时子矩阵中宽度为`j-i+1`（双闭区间）的子矩阵有`r-l+1`（双闭区间）行，每次只计算当前行数的组合种类，枚举结束就是所有组合后依旧满足条件的组合，**举例说明就是$A_{33} = 1 + 2 + 3$而不是$A_{33} = 3*2$** 所以其**对答案的贡献为`r-l+1`**，类似[AcWing 1230. K倍区间](obsidian://open?vault=c%2B%2B&file=%E7%AE%97%E6%B3%95%2F%E7%AE%97%E6%B3%95%E5%9F%BA%E7%A1%80%2F%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95%2F%E5%89%8D%E7%BC%80%E5%92%8C%E4%B8%8E%E5%B7%AE%E5%88%86%2FAcWing%201230.%20K%E5%80%8D%E5%8C%BA%E9%97%B4)、

 若慢指针`l>j`（越界），则不操作，直接进入下层循环

```c++
 LL res = 0;
    for (int i = 1; i <= m; i++)
    {
        for (int j = i; j <= m; j++)// i,j左右边界
        {
            for (int l = 1, r = 1; r <= n; r++)// //l,r上下边界
            {
                while (l <= r && (s[r][j] - s[l - 1][j] - s[r][i - 1] + s[l - 1][i - 1]) > k) 
                {
                    l++;
                }

                if (l <= r)
                {
                    res += r - l + 1;
                }
            }
        }
    }
```

**易错`！！！！！！！！！！！！！！！！！`**
-- -
- 下列代码有误，不可提前使用`sum`获取`s[r][j] - s[l - 1][j] - s[r][i - 1] + s[l - 1][i - 1]`的值，在`while`循环中，`l`的值是不断变化的，所以矩阵和也应该不断变化。正如在使用`vector`时，使用`xx.begin();xx.end();xx++`，也是因为`vecotr`的长度是可变的
- 下面一维前缀和中之所以可是使用`sum`记录，是因为在内部`sum`会随`l`的变化
---
```c++
 for (int l = 1, r = 1; r <= n; r++)// //l,r上下边界
            {
                int sum =s[r][j] - s[l - 1][j] - s[r][i - 1] + s[l - 1][i - 1];
                while (l <= r && sum > k) 
                {
                    l++;
                }

                if (l <= r)
                {
                    res += r - l + 1;
                }
            }
```
## 将列看作一个整体

- 参考：[L - China题解](https://www.acwing.com/solution/content/178949/)
- 使用**一维前缀和**处理初始矩阵和**双指针**优化枚举
- 时间复杂度：$O(n^3)$
- `i`,`j`枚举列的上下边界，通过双指针`l`,`r`维护列的左右边界
- `sum`存储枚举列的和，如果`sum>k`了，列的左边界`l++`，直到`sum<=k`
- `res`记录一下从`l`到`r`这一段列的贡献：`r−l+1`,原理同上

```c++
 for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            scanf("%d", &ans[i][j]);
            s[i][j] = s[i - 1][j] + ans[i][j]; // 每列上的一维前缀和
        }
    }

    LL res = 0;
    for (int i = 1; i <= n; i++) // i,j上下边界
    {
        for (int j = i; j <= n; j++)
        {
            LL sum = 0;//涉及到循环时,不要随意修改变量初始化的位置

            for (int l = 1, r = 1; r <= m; r++) //l,r左右边界
            {
                sum += s[j][r] - s[i - 1][r];
                while (sum > k)
                {
                    sum -= s[j][l] - s[i - 1][l];
                    l++;
                }

                res += r - l + 1;
            }
        }
    }
```
