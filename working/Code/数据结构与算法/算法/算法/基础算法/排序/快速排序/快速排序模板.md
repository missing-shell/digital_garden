```C
void quickSort(int L, int R) {
	if (L==R) return;  
	int i = L - 1, j = R+ 1, x = ans[(L+R) / 2]; //选取中间位置作为基准 
	while (i < j)
	{
		while (ans[++i] < x);	 //从右向左找到比x小的数
		while (ans[--j] >x );	 //从左向右找到比X大的数
		if (i < j) swap(ans[i], ans[j]);//交换两个数的位置
	}  
	quickSort(L, j);//递归
	quickSort(j + 1, R);

}
```
### 思路
快速排序 -- 基于分治
- 确定分界点  左右边界 中间点

- 调整区间  分界点左边 <=x  分界点右边  >=x
