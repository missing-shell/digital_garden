# 贪心 双指针
## 贪心

 - 参考：[小虎成员](https://www.acwing.com/solution/content/101156/)
 
- 分解题目:  给你一个数组`a[N]`，一共有N个数，用指数`h`，来描述数组，`h`代表至少有`h`个数大于等于`h`(最大的`h`),然后给我们一个数`L,`我们可以选择最多`L`个数，使得每个数都加`1`,然后求出最大的指数`h`。

- 将数组按照**降序进行排序**，然后当`a[i]>=i` 且`i`最大的时候，`i`就是我们当前数组的指数

- 首先要判断出，每个数最多只能加1，所以h指数最大只能是h+1,
	 
	证明：当前指数是`h`，`a[h]>=h`,`a[h+1]<h+1`,由于`a[h+1]<h+1,`所以`a[h+1]`最多只有变成`h+1,`不会变成`h+2`,更不会变更大。
	在数组后面的数中，由于是逆序排列的，所以也小于等于`h+1,`更不可能变成`h+2`，由此可知，指数最大只能是`h+1`
  
- 所以我们现在要做的是选择部分数，然后让他们加1后使得`a[h+1] == h+1`,首先就是要选择`a[h+1]`这个点，在这里进行判断，如果`a[h+1]<h`的话，就不可能变成`h+1`了(因为一个数最多加`1`)，所以最大指数就是`h`

- 如果`a[h+1] == h`的话，要找逆序排列中在`1~h+1`，这个范围中有多少个点等于`h(cnt个)`，这些点都需要加`1`，因为这些点都需要大于等于`h+1`,所以，**至少需要`cnt`个点，当`cnt<=L`的时候满足条件，指数是`h+1`,否则是h

- 个人总结
	要仔细理解题目，简化题目
	既然都用到了`sort`和`n-j`,应该考虑下降序排列
	没有预先判断出指数最大为`h+1`
	如果代码中出现了许多`leap`等特殊判断条件，打了大量的补丁，那就说明代码的思路错了。
```c++
#include <iostream>
#include <algorithm>

using namespace std;

const int N = 1e5 + 10;

int ans[N];

bool cmp(int x, int y)
{
    return x > y;
}

int main()
{
    int n, m;
    cin >> n >> m;

    for (int i = 1; i <= n; i++)
    {
        cin >> ans[i];
    }

    sort(ans + 1, ans + n + 1, cmp);

    int res = 0;

    for (int i = 1; i <= n; i++)
    {
        if (ans[i] >= i)
        {
            res = i;
        }
        else
        {
            break;
        }
    }

    if (ans[res + 1] >= res)
    {

        int cnt = 0;
        for (int i = 1; i <= res+1; i++)
        {
            if (ans[i] == res)
            {
                cnt++;
            }
        }
        if(m>=cnt)
        {
            res++;
        }
    }
    cout << res << endl;
    return 0;
}
```
