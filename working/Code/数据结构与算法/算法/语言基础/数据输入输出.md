## 输入

### fgets

fgets(buf MAXN，fin)读取完整的一行，其中 buf 的声明为 char buf[MAXN]。这个函数读取不超过 MAXN-1 个字符，然后在末尾添上结束符\0'，因此不会出现越界的情况。之所以说可以用这个函数读取完整的一行, 是因为一旦读到回车符"n”，读取工作就会停止，而这个'\n'也会是buf字符串中最后一个有效字符（再往后就是字符串结束符'\0'）。
### getchar

```c++
##include<iostream>
#include<cstring>
using namespace std;
int main()
{
	int x=0,sum=0;
	char c='1';
	while ((c = getchar()) != '\n') {
		if (c == '-') {
			cout << "-";
		}
		else {
			x = 10 * x + c - '0';
		}
	}
	cout << x << endl;
	return 0;
}

```
### cin
cin判断结尾的标志是换行和空格

当读取字符串时，若行尾有多余的空白字符，可能会导致结果不准确。建议使用 `cin.getline()` 替换 `scanf("%s", ans[i])` 来更安全地读取一行字符。

### scanf
```c++
char c,op[2];
scanf("%c",&c);//无法忽略空格换行符
scanf("%s",op);//自动忽略空格和换行符，可替代读取字符!!!!!!
```
