### Java基础概念复习整理

#### 基础概念
1. **Java源文件和编译后的文件扩展名**：(B) .java和 .class
   - 解析：Java源代码文件以.java为扩展名，编译后生成的字节码文件以.class为扩展名。

2. **不能插入到行1的选项**：(D) public class MyClass{ }
   - 解析：在类声明之前，可以有import语句、package语句或其它类的声明，但不能直接声明另一个public类，因为一个文件中只能有一个public类，且文件名必须与此public类名一致。


4. **错误引用数组元素**：(C) a[k+5]
   - 解析：数组索引超出界限，假设k最大为3，k+5会超出数组长度4。

5. **Java原始数据类型**：(D) char
   - 解析：char是Java的基本数据类型之一，而Boolean、Float、String均不是原始类型，String是类。

6. **类与对象的关系**：(A) 类是对象的抽象
   - 解析：类定义了一组属性和行为的模板，而对象是类的实例，具备类定义的特性和行为。

7. **关于抽象方法的说法错误的**：(C) 抽象类中的方法都是抽象方法
   - 解析：抽象类可以有非抽象方法。

8. **switch(expression)中expression的数据类型不能是**：(B) double
   - 解析：switch不支持double类型的表达式。

9. **所有错误、异常类的基类**：(B) Throwable
   - 解析：Throwable是Java异常体系的根类，所有异常和错误都继承自它。

10. **构造ArrayList实例**：(B) List myList=new ArrayList( );
    - 解析：使用ArrayList类需要实例化，通过new关键字，并且**由于ArrayList实现了List接口**，可以使用List作为引用类型。

11. **修饰符修饰的类成员可在子类重写**：(B) protected
    - 解析：protected成员可以在同一包或子类中访问，因此可以被子类重写。

12. **生成异常的关键字**：(D) throw
    - 解析：throw用于手动抛出异常。

13. **声明了返回类型的方法，其方法体中一定具有的关键词是（C）return**。
    - 解析：在Java中，任何具有返回类型（非void）的方法体内必须至少包含一条return语句，用于返回与方法声明类型匹配的值。

14. **以下关于继承的叙述正确的是（A）在Java中类可以通过实现多个接口来实现多重继承**。
    - 解析：Java不支持类的多重继承，即一个类只能直接继承一个父类。但是，一个类可以实现多个接口，以此达到类似多重继承的效果，实现接口的多重继承。

4. **在类的定义中可以有两个同名函数，这种现象称为函数（D）重载**。
    - 解析：这是方法重载（overloading）的概念，即在同一个类中可以有多个方法名相同但参数列表不同的方法。

5. **在类的定义中构造函数的作用是（D）初始化成员变量**。
    - 解析：构造函数的主要任务是在创建对象时初始化对象的状态，即为成员变量赋予初始值。

6. **下面关键字中，哪一个不是用于异常处理语句（B）break**。
    - 解析：在异常处理中，try、catch、finally是关键结构，而break通常用于循环控制或switch-case结构中。

7. **类与对象的关系是（A）类是对象的抽象**。
    - 解析：类是对具有相似属性和行为的一组对象的抽象描述，而对象是类的实例，是类的具体表现。

8. **下面哪一个是Java中不合法的标识符（D）*point**。
    - 解析：Java标识符不能以特殊字符（如*）开头，必须以字母、下划线( _ )、美元符号($)开头。

9. **为AB类的一个无形式参数无返回值的方法method书写方法头，使得使用类名AB作为前缀就可以调用它，该方法头的形式为（A）static void method()**。
    - 解析：为了让方法能通过类名调用，该方法必须是静态方法（static），并且由于没有返回值，返回类型为void，无参数则参数列表为空。

10. **欲构造ArrayList类的一个实例，此类继承了List接口，下列哪个方法是正确的（B）List myList = new ArrayList();**
    - 解析：ArrayList实现了List接口，因此可以将ArrayList实例赋给List类型的引用，这是多态性的体现。

19. **关于抽象方法的说法正确的是（C）是没有方法体的方法**。
    - 解析：抽象方法只有声明没有具体实现（方法体），需要==在子类中被具体实现==。

21. **Java application中的主类需包含main方法，以下哪项是main方法的正确形参？（B）String args[]**
    - 解析：main方法的标准签名是`public static void main(String[] args)`，其中args是一个字符串数组，用于接收命令行参数。

22. **以下代码段执行后的输出结果为（C）1**。
    - 解析：取余操作（`%`），例如`y%x`，其中`x`和`y`是整数，结果的符号（正负）与`y`相同。也就是说，如果`y`是负数，那么结果也会是负数，反之亦然。而整数除法在Java中会截断小数部分，不考虑余数。

23. **以下关于继承的叙述正确的是（A）在Java中类只允许单一继承**。
    - 解析：Java遵循单继承原则，一个类只能直接继承一个父类，但可以通过实现多个接口来实现类似多重继承的功能。

24. **若有定义：byte[] x={11,22,33,-66}; 其中0≤k≤3，则对x数组元素错误的引用是（C）x[k+5]**。
    - 解析：数组x的索引范围是0到3，x[k+5]会导致数组越界错误。

26. **以下哪个不是Java的原始数据类型（D）char[]**
    - 解析：char[]是一个字符数组，属于引用类型，而非原始数据类型。

27. **在Java中，一个类可同时定义许多同名的方法，这些方法的形式参数的个数、类型或顺序各不相同，传回的值也可以不相同。这种面向对象程序特性称为（C）重载**。
    - 解析：描述的是方法重载（overloading）的概念，即在一个类中允许有多个同名方法，但它们的参数列表或返回类型不同。

28. **以下有关构造方法的说法，正确的是：（A）一个类的构造方法可以有多个**。
    - 解析：一个类可以定义多个构造方法，只要它们的参数列表不同，这称为构造方法的重载。

30. **给出下面代码，关于该程序以下哪个说法是正确的？（C）输出空**
    - 解析：代码中定义了一个静态数组arr，并初始化为长度为5的字符串数组，但没有给数组元素赋值，因此`System.out.println(arr[0]);`会输出null，这里视为“空”。

31. **有以下方法的定义，请选择该方法的返回类型（D）double**
    - 解析：ReturnType method(byte x, double y) { return (short)x/y* 2; }，虽然return语句中涉及到了short类型的计算，但最终结果会根据操作数的类型提升为double类型返回。
### 填空题答案及解释

1. 表示继承父类使用的关键词是 **extends**。
   - 解释：在Java中，类通过使用`extends`关键字来继承另一个类，从而获得父类的属性和方法。

2. 引入外部类的关键词是 **import**。
   - 解释：为了使用不在当前包内的类，需要使用`import`语句来导入这个类或整个包。

3. `super()`表示的是 **父类的构造方法**。
   - 解释：在子类构造方法中，`super()`用于调用父类的无参构造方法，以初始化继承自父类的成员变量。

4. 判断整型变量n除3余数是否等于2 的Java语言表达式是 **n % 3 == 2**。
   - 解释：使用取模运算符 `%` 来计算余数，然后与2进行比较。

5. 下段程序的运行结果是 **s=10**。
   - 代码分析：由于 `i` 的值为0，只会执行 `case 0` 里的语句，s 的值被加10后立即break，所以输出s的值为10。

6. 实现接口使用的关键词是 **implements**。
   - 解释：要让一个类遵循特定的接口规范，需要使用`implements`关键字。

7. 引入MyPackage包内所有类的语句是 **import _MyPackage._ *  ;**。
   - 解释：使用`import`语句加上星号(`*`)可以一次性导入包内的所有类。

8. 数组中的 **length** 属性存储的内容为数组的长度。
   - 解释：数组对象有一个内置的属性`length`，它表示数组中元素的数量。

9. String类中的 **indexOf()** 方法可以实现获取字符串中的某一字符第一次出现的位置。
   - 解释：`indexOf()`方法返回指定字符或子串在字符串中首次出现的索引，未找到则返回-1。

10. `this()`表示的是 **本类的无参构造方法**。
    - **this** 关键字用于引用当前对象的属性和方法。**super** 关键字用于引用父类中的属性和方法，特别是在子类中重写父类方法时。

11. `String str1 = "hello"; String str2 = new String("hello"); System.out.println(str1 == str2);` 结果为 **false**，反过来为 **true**。
    - 解释：这是因为`str1`是**字符串池**中的引用，而`str2`是堆上的新对象。直接比较引用时为false，但比较内容时（使用`.equals()`方法）为true。

### 简答

1. **继承**是面向对象编程中的一个核心概念，允许子类继承父类的属性和方法，从而实现代码复用和层次结构的建立。**父类**是被继承的类，提供了基础的属性和行为；**子类**则继承父类并可以添加或重写父类的方法，实现更具体的实现。继承的好处包括减少代码重复、支持多态、提高代码的组织性和模块化程度。

3. **重载**(Overloading)指的是在同一个类中可以有多个同名方法，它们之间的区别在于参数列表不同。**覆盖**(Overriding)发生在继承关系中，子类可以提供一个与父类中已存在的方法签名完全相同的方法实现。 覆盖关注的是方法实现的替换，而多态则是关于接口的统一和实现的多样性。

5. **异常**是在程序执行期间发生的问题，可以被捕获并处理以避免程序崩溃。在Java中，通过`try-catch`块来捕获异常，使用`throw`语句抛出异常。异常类通常继承自`java.lang.Throwable`类，其中`Exception`和`Error`是最常见的两个子类。

6. **类的成员访问修饰符**有：
   - **public**：任何地方都能访问。
   - **protected**：同包内或子类中可以访问。
   - **private**：仅在定义它们的类中可访问。
   - **default**（未明确指定时）：仅在同一个包内可访问。

7. **this**关键字用于引用当前对象，常用于区分同名的局部变量和实例变量，或者调用本类的构造方法。**super**关键字用于访问父类的成员变量和方法，或调用父类的构造方法。

9. **构造方法的执行顺序**：首先执行父类的构造方法（如果没有显示调用父类构造方法，则默认调用父类的无参构造方法），然后执行子类自己的构造方法。

### 问答题
1. **接口** 是一种==引用==类型，可以包含抽象方法和默认方法，但不能包含实现。接口的特点包括：
   - 可以被任何类实现（implements）。
   - 接口中的方法**默认是public和abstract的**。
   - 接口可以包含常量，不能有变量。
   - 接口可以多实现。接口的作用包括定义规范、实现多继承等。
 
1. **非访问修饰符**包括static、final、abstract、transient、volatile等。**static**修饰的成员属于类而不属于对象，可以无需实例化直接访问，且在内存中只有一份。与非static成员的区别在于生命周期和存储位置。
