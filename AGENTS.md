# AGENTS.md

## Project

Quartz v5 — a static-site generator for publishing Markdown notes as a website. This repo is a personal digital garden (Chinese-language embedded systems notes in `working/`) built on the upstream Quartz framework.

## Key commands

| Command | What it does |
|---|---|
| `npm run check` | Type-check (`tsc --noEmit`) + Prettier format check |
| `npm run format` | Auto-format all files with Prettier |
| `npm run test` | Run test suites via `tsx --test` |
| `npx quartz build -d working` | One-shot build: processes `working/` → outputs to `public/` |
| `npx quartz build -d working --serve` | Build + live-preview on port 8080 |
| `npx quartz plugin install` | Install community plugins from lockfile |

## Architecture

- **`working/`** — user Markdown notes (the garden itself). ~467 files across embedded systems, C/C++, Linux, networking, algorithms, etc.
- **`quartz/`** — framework source. Plugins loaded from GitHub (`github:quartz-community/*`).
- **`quartz.config.default.yaml`** — single user config: global settings, theme, plugins, layout (YAML, not TypeScript).
- **`quartz.lock.json`** — plugin version lockfile (auto-generated by `npx quartz plugin install`).
- **`quartz.ts`** — thin entrypoint that loads YAML config.
- **Build output** → `public/` (gitignored).
- **Plugin cache** → `.quartz/plugins/` (gitignored).

## Environment

- **Node**: >=22 (`.node-version`: v22.16.0). Use `nvm use` or `fnm use`.
- **npm**: `>=10.9.2`, `engine-strict=true` in `.npmrc`.
- **Module system**: ESM (`"type": "module"` in `package.json`).
- **TSX**: JSX configured for Preact (`"jsxImportSource": "preact"`).
- **TypeScript**: strict mode, esnext target, node module resolution.

## Conventions

- **Prettier**: 100-char print width, no semicolons, trailing commas, 2-space tabs.
- **Config**: YAML-only. No separate layout file in v5.
- **Plugin install**: Run `npx quartz plugin install` before first build (or after config changes).

## GitHub Pages deployment

- Workflow at `.github/workflows/deploy.yml` — triggers on push to `v5`.
- `baseUrl` set to `missing-shell.github.io/digital_garden` in config.
- SPA disabled (`enableSPA: false`) — links use `.html` extensions for GitHub Pages compatibility.
- `.nojekyll` added in CI to disable Jekyll processing.
- Site URL: https://missing-shell.github.io/digital_garden/
